# ADR 003 — one composition workspace, no audio compatibility product

Accepted 2026-09-27 by explicit user direction. Supersedes the legacy-preservation portions of ADR 002 and older handoffs.

Pocket Producer is unreleased. Keeping a second generated-audio history made two unrelated musical products look like views of one song. Remove that workflow, not merely its navigation: planner/compiler/renderer, repair loop, whole-piece player, audio A/B, old endpoints and stem export. Do not create archives, redirects, converters or read-only legacy screens.

Retain useful shared source media handling, canonical hashing, accounted OpenAI runtime/checkpoints, native document/tools/jobs/history, source analysis boundary and native Nexus synchronization. The logo and established arrangement/inspection visualizations stay.

Delete specifically inventoried obsolete audio-only test project content. Never infer deletion from a title or delete native unfinished work. Preserve financial audit rows and unknown liabilities via minimal deleted project/job identities. Historical migration files are not product compatibility and remain untouched; no native music is synthesized from old audio data.

In-app native listening remains deferred. Audiotool copying is explicit, not triggered by navigation or automatic version selection. A source audition plays the source only. The future audio boundary must attach verified audio to an exact native version; it must not resurrect an unrelated history.
