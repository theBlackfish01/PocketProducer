# Native producer tool recovery

The Deep Agent receives expected tool mistakes as short, structured feedback. The tool-call middleware pre-validates Zod arguments before LangChain can turn a schema rejection into a verbose stack-bearing tool message. It also catches local Nexus path syntax, missing pinned entities or fields, unavailable optional Audiotool library access, and stale inspection identifiers. Parallel read-only tool results survive a sibling's correctable error. Discovery includes a known-valid schema path example; it never grants write authority.

Each repeated identical failed call is counted only within the current graph invocation. At three failures the feedback tells the producer to take a supported alternative. This is guidance, not an unbounded retry loop: captured model-call, cost and deadline ceilings still apply. The model cannot override operation validation, protected parts, ownership or the lease. No raw tool stack is returned for the handled cases.

Cancellation, lease/deadline loss, replay conflicts, uncertain effects and unexpected failures do not become ordinary tool feedback. If an unexpected tool failure escapes LangGraph, the producer checks current job authority and that every model call has a confirmed outcome. Only then does it leave the aggregate producer effect dispatched and pause the same logical job as continuable, with the plan and confirmed steps retained and no new version selected. An unknown model outcome remains fenced rather than being re-dispatched. A fresh continuation uses the existing request, captured budget and replayed steps; it does not automatically spend more.

Provider-free verification: `packages/core/src/native/tool-recovery.test.ts` covers classification and the safety boundary; `tests/native-construction.test.ts` checks pinned schema fields; `tests/integration/native-tool-recovery.test.ts` drives the actual worker/Deep Agent/PostgreSQL path through parallel invalid paths, schema rejection, optional library failure, a corrected inspection and committed music. It also verifies an unexpected tool failure pauses before construction and resumes on the same request without repeating the first model call. LangSmith input/output hiding remains enabled; this behavior is not a claim of live-model quality or live Nexus fidelity.
