PostgreSQL grants and checks custody

The database claim uses a transaction and a row lock to hand a job to exactly one worker.

CODE 
    const active = await client.query<{ state: string; cancellation_requested_at: Date | null; deadline_at: Date }>(
      `UPDATE job SET stage=COALESCE($5,stage),updated_at=now()
       WHERE id=$1 AND lease_owner=$2 AND lease_generation=$3 AND attempt_id=$4 AND lease_until>now() AND deadline_at>now()
       RETURNING state,cancellation_requested_at,deadline_at`,
      [job.id, job.leaseOwner, job.leaseGeneration, job.attemptId, stage ?? null]
    );
    const row = active.rows[0];
    if (!row) throw new JobControlError("LEASE_LOST", "Worker lease or deadline rejected progress");
    if (row.cancellation_requested_at || row.state === "cancel_requested") throw new JobControlError("CANCELLED", "Cancellation requested");
    if (row.state !== "running") throw new JobControlError("LEASE_LOST", "Job is no longer running");
    await insertJobEvent(client, job.id, eventType, payload);
PLAIN ENGLISH

Ask PostgreSQL to append progress only while every custody field still matches this worker.

Match the job, worker, lease generation, and unique attempt ID.

Use database time to require both a live lease and an unexpired absolute deadline.

If nothing matched, classify the in-memory worker as stale.

Treat a cancellation request as a separate terminal path, not ordinary progress.

Require the durable state to remain running.

Only then allocate and append the next ordered job event.

Finishing work is a second permission check

A commit fence asks whether the same worker still owns the same lease generation before changing durable state.

1

Generation + attempt

Reject an old worker whose job was reclaimed with a newer generation or a different attempt UUID.

2

Cancellation

Reject a result when cancellation was recorded before the final write.

3

Current state

Require the job to remain running instead of trusting an outdated in-memory copy.

4

Project head

A project head advances only when it still matches the version this job expected.

✓

Valid but no longer latest

Keep the immutable revision as a successful result, but do not silently replace a newer project head.

✕

Invalid custody

Reject the commit when the lease generation, running state, or cancellation check fails.

A scoped edit, not a rewrite

“Simplify the drums” targets hi-hats inside the Groove section only. The function clones the composition, removes every second matching hat, and returns both the new version and an exact count.

CODE · packages/core/src/music/compiler.ts 
export function simplifyDrums(base: Composition): { composition: Composition; removed: number } {
  const groove = base.sections.find((section) => section.id === "groove");
  if (!groove) throw new Error("Composition has no Groove section");
  let removed = 0;
  const tracks = base.tracks.map((track) => {
    if (track.id !== "drums") return structuredClone(track);
    let hatIndex = 0;
    const events = track.events.filter((item) => {
      const inScope = item.startTick >= groove.startTick && item.startTick < groove.endTick;
      if (!inScope || !item.assetId.includes(":hat")) return true;
      hatIndex += 1;
      const keep = hatIndex % 2 === 1;
      if (!keep) removed += 1;
      return keep;
    });
    return { ...structuredClone(track), events };
  });
  return { composition: { ...structuredClone(base), tracks }, removed };
}
PLAIN ENGLISH

Accept the base composition and promise to return a new composition plus the number of removed events.

Find the Groove section; stop with a clear error if the composition does not have one.

Start the removal count at zero, then visit every track.

For any track that is not drums, return a deep copy unchanged. structuredClone protects the base revision.

For the drum track, inspect each event and ask whether it falls inside the Groove’s start and end ticks.

Leave events outside the section—and non-hat sounds inside it—untouched.

Count only the in-scope hats, keeping the first, third, fifth, and so on while counting each removed alternate hat.

Return a cloned composition with the filtered drum events and the measured removal total.
