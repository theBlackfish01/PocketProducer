04 / Deep Agent

The producer proposes. The application decides.

OpenAI powers a Deep Agents/LangGraph producer. It plans a form, inspects the current score, proposes small operations, and refines. Trusted domain code—not the model’s confidence—decides what can be saved.

The plan and confirmed steps outlive one model conversation or worker process. A graph pause does not erase a logical job.

Explore the producer’s toolbox

Tool names reflect real implementation. A read or discovery tool is not write authority.

Plan and retain intent

record_native_plan, read_native_plan, advance_native_stage, and read_native_brief keep musical intention durable. The full direction is retained; long text can be paged instead of repeated in every prompt. A plan is progress, not accepted music.

Inspect current facts

Workspace, section, part, motif, and owned-source inspection return bounded, current data. The source profile measures duration and activity—not semantic listening. After its last mutation a real-model run must review two current sections before completion.

Learn what is possible

Capability discovery and local resource search expose supported devices and operations. Connected Audiotool preset, sample, and GM searches are server-mediated. Search metadata is not permission to write unsupported fields and does not establish usage rights.

Apply only validated changes

compose_native_form can begin a new piece. apply_native_batch is the general mutation entry for notes, motifs, clips, instruments, routing, effects, and automation. The model cannot invoke protect through it, run a shell, render audio, ask Gemini to hear native music, or mutate Audiotool directly.

Scoped workspace

Useful context, narrow authority

The agent has a virtual workspace, repository-local arrangement/revision/sound-design skills, and a PostgreSQL graph checkpointer. Reads are scoped; arbitrary filesystem writes are denied.

Independent completion gate

A valid batch can still be wrong

After construction, code checks explicit bars, tempo, meter, roles, exclusions, sources, chord pitch classes, processing requests, and required revision change. A structurally legal but wrong proposal goes back for correction.

Where the model is deliberately limited.

“Keep bass” is not “no bass”; “bring in chords” is not a section title. The intent interpreter handles bounded explicit forms and flags ambiguity. The completion gate cannot prove taste, voice leading, or acoustic mix perception.
