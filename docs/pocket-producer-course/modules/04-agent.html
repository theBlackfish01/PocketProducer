04 / Models + Deep Agent

The producer proposes. The application decides.

One Deep Agents/LangGraph workflow runs through the captured OpenAI Sol, OpenAI Luna xhigh, or Gemini Flash route for new work. It plans a form, inspects the score, proposes validated operations and refines. Trusted domain code—not model confidence—decides what can be saved.

A durable creative loop

The selected model, reasoning and price snapshot stay fixed for a job. Its plan and confirmed steps outlive a conversation or worker process; a graph pause does not erase a logical job.

Explore the producer’s toolbox

Tool names reflect real implementation. A read or discovery tool is not write authority.

Plan and retain intent

record_native_plan, read_native_plan, advance_native_stage, and read_native_brief keep musical intention durable. The full direction is retained; long text can be paged instead of repeated in every prompt. A plan is progress, not accepted music. Standard and Extended are engineering ceilings, not authorization to spend their full amounts.

Inspect current facts

Workspace, section, part, motif, and owned-source inspection return bounded, current data. The source profile measures duration and activity—not semantic listening. After its last mutation a real-model run must review two current sections before completion.

Learn what is possible

Capability discovery and local resource search expose supported devices and operations. Original versioned sound recipes guide musical choices without becoming fixed genre generators or heard claims. Connected Audiotool preset, sample, and GM searches are server-mediated; search metadata is not write authority or proof of usage rights.

Apply only validated changes

compose_native_form can begin a new piece. apply_native_batch is the general mutation entry for notes, motifs, clips, instruments, routing, effects, and automation. The model cannot invoke protect through it, run a shell, render audio, ask Gemini to hear native music, or mutate Audiotool directly.

Captured routes

One workflow, three choices

GPT-6 Sol and GPT-6 Luna xhigh use OpenAI Responses; Gemini 3.7 Flash uses Google's compatible route. Historical DeepSeek V4 Pro 0813/Gateway jobs remain readable, but DeepSeek is not selectable for a new request. Selection is not proof of credit or live success. Rewrite/Inspire uses a separate bounded Luna helper.

Scoped workspace

Useful context, narrow authority

The agent has a virtual workspace, repository-local arrangement/revision/sound-design skills, and a PostgreSQL graph checkpointer. Reads are scoped; arbitrary filesystem writes are denied.

Independent completion gate

A valid batch can still be wrong

Code checks explicit bars, tempo, meter, roles, exclusions, sources, chords, processing and required revision change. A focused symbolic critic adds musical judgment, but it does not hear audio; unavailable review is never a clean endorsement.

Where the model is deliberately limited.

“Keep bass” is not “no bass”; “bring in chords” is not a section title. A submit-time interpretation keeps only items that quote the user's words and name real parts; unmatched words are shown and sent as guidance, never as hidden locks. The completion gate cannot prove taste, voice leading, or acoustic mix perception.
