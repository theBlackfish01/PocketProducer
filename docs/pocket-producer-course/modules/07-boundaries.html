07 / Integrations

Crossing into Audiotool is a separate, explicit job.

Nexus is an editability boundary, not a hidden render engine. Gemini is an independent audio-analysis adapter for selected source/sample analysis and future listening, not a listener for native documents.

Fidelity has levels

Native notes and mapped controls can remain editable; an audio clip stays an audio clip; source audio does not become editable MIDI notes.

Follow explicit native synchronization

Offline tests cover the general contract. The Midnight Escalator score additionally has matching live v7 readback; this is not acoustic evidence or proof for every feature.

Choose one immutable version

The user explicitly requests “Copy to Audiotool.” The worker preflights a mapped native document and selected resource identities. The pinned @audiotool/nexus@0.0.17 mapper is nexus-native-v7; offline SDK validation checks more than object counts.

Record creation before contacting the provider

The sync ledger captures intent and checkpoints the returned project identity. An ambiguous create outcome is fenced rather than repeated into a second project. The adapter refuses to overwrite an occupied target automatically.

Resolve every selected source

Owned WAVs carry source-hash identities, upload/readiness checkpoints, and sample-region mapping. Library samples and presets are re-resolved against recorded identity/fingerprint facts. A local source placement alone is not remote evidence.

Map into an empty project

The adapter converts the score’s 960 PPQ time to the SDK’s 3840 scale and writes supported notes, patterns, instruments, clips, groups, effects, sends, and automation. Unsupported or unsafe approximations fail rather than silently changing meaning.

Reopen for semantic readback

A fresh project read checks the mapped structure. Only a matching version hash under the current mapper version can be labeled verified. Rechecking a verified project reads without overwriting edits a person made in Studio.

Audiotool session

Consent and encrypted tokens

OAuth/PKCE browser consent has worked previously. Tokens are owner-bound and encrypted server-side. The observed grant lacked usable refresh, so an expired connection needs reconnection. The Midnight Escalator project was reopened twice and structurally matched under v7 after a read-only reconciliation; no duplicate project was created.

Current live limit

One verified score, bounded evidence

Midnight Escalator's mapped notes, regions, channels and automation matched fresh readback. Source-bearing synchronization and the full routing/device range still need separate live verification. A direct render RPC previously returned operation IDs without a retrievable audio artifact. Native playback remains deliberately deferred.

Gemini and future listening

Separate adapter

Audio facts versus opinion

The Gemini adapter keeps typed observations separate from measured duration, peak, RMS, and non-silent ratio. The native producer can request bounded, budgeted character analysis of shortlisted sample audio; no whole-composition listening or render–repair loop is shipped.

Honest provider state

Unknown is not success

The retained targeted Gemini attempts failed after dispatch with no response metadata. Their billing/outcome remain uncertain and are not automatically retried. Gemini is not used to hear native scores.
