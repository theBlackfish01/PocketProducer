07 / Integrations

Crossing into Audiotool is a separate, explicit job.

Nexus is an editability boundary, not a hidden render engine. Gemini is an independent audio-analysis adapter for selected source/sample analysis and future listening, not a listener for native documents.

Fidelity has levels

Native notes and mapped controls can remain editable; an audio clip stays an audio clip; source audio does not become editable MIDI notes.

Follow explicit native synchronization

Current nexus-native-v8 has offline SDK evidence. Midnight Escalator has matching historical live nexus-native-v7 readback; neither is acoustic evidence or proof for every feature.

Choose one immutable version

The user explicitly requests “Copy to Audiotool.” The worker preflights a mapped native document and selected resource identities. Pinned @audiotool/nexus@0.0.17 is used by the current nexus-native-v8 mapper; offline SDK validation checks semantic content, not only object counts.

Record creation before contacting the provider

The sync ledger captures intent and checkpoints the returned project identity. An ambiguous create outcome is fenced rather than repeated into a second project. The adapter refuses to overwrite an occupied target automatically.

Resolve every selected source

Owned WAVs carry source-hash identities, upload/readiness checkpoints, and sample-region mapping. Library samples and presets are re-resolved against recorded identity/fingerprint facts. A local source placement alone is not remote evidence.

Map into an empty project

The adapter converts the score’s 960 PPQ time to the SDK’s 3840 scale and writes supported notes, patterns, instruments, clips, groups, effects, sends, and automation. Unsupported or unsafe approximations fail rather than silently changing meaning.

Reopen for semantic readback

A fresh project read checks the mapped structure against the recorded version and mapper identity. Rechecking a verified project reads without overwriting edits a person made in Studio. Historical v7 verification cannot certify new v8 sound semantics.

Gemini and future listening

Separate adapter

Audio facts versus opinion

The Gemini audio adapter keeps typed character observations separate from measured duration, peak, RMS and activity. The native producer can request bounded, budgeted opinion on shortlisted sample audio; this is distinct from selecting Gemini Flash as the text producer. No whole-composition listening or render–repair loop is shipped.

Honest provider state

Unknown is not success

Retained targeted Gemini audio attempts failed after dispatch with no response metadata. Their billing/outcome remain uncertain and are not automatically retried. Gemini has not heard these native scores.
