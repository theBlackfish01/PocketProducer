Lock the job row and compare its worker, lease generation, and unique attempt ID.

Return CANCELLED when cancellation won the race.

Return DEADLINE_EXCEEDED when the absolute job deadline expired.

Return LEASE_LOST only when this attempt no longer owns a live running lease.

The monitor separately uses MONITOR_UNAVAILABLE if PostgreSQL cannot be consulted.

Update progress only after the typed control check passes.

Only then allocate and append the next ordered job event.

Finishing work is a second permission check

A commit fence asks whether the same worker still owns the same lease generation before changing durable state.

1

Generation + attempt

Reject an old worker whose job was reclaimed with a newer generation or a different attempt UUID.

2

Cancellation

Reject a result when cancellation was recorded before the final write.

3

Current state

Require the job to remain running instead of trusting an outdated in-memory copy.

4

Project head

A project head advances only when it still matches the version this job expected.

✓

Valid but no longer latest

Keep the immutable revision as a successful result, but do not silently replace a newer project head.

✕

Invalid custody

Reject the commit when the lease generation, running state, or cancellation check fails.
