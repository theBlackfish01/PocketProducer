The producer’s room, in real code

The constructor connects the model, its single tool, its output contract, and its durable memory. The system prompt makes the boundary unusually explicit: propose a plan, never pretend to hear, and leave exact events to deterministic code.

    const agent = createDeepAgent({
      name: "pocket-producer",
      model,
      tools: [paletteTool],
      responseFormat: providerStrategy(arrangementPlanSchema),
      checkpointer: await checkpoint(),
      skills: ["/skills/"],
      permissions: [
        { operations: ["read"], paths: ["/"] },
        { operations: ["read"], paths: ["/skills/**", "/workspace/**"] },
        { operations: ["write"], paths: ["/**"], mode: "deny" },
        { operations: ["read"], paths: ["/**"], mode: "deny" }
      ],
      systemPrompt: "You are Pocket Producer's main producer. Read /skills/arrange-short-instrumental/SKILL.md and /workspace/brief.md, call list_supported_palettes once, then immediately return one valid compact arrangement plan. Do not list the filesystem. Never claim to hear audio. Do not create raw timeline events; deterministic application code compiles the plan."
    });
    const agentInput = { messages: [{ role: "user", content: "Plan this supported instrumental now. Use the source when one is available." }], files: await runtimeFiles(input.direction, input.hasSource) };
    const result = await agent.invoke(
      agentInput as never,
      { configurable: { thread_id: input.jobId }, recursionLimit: 24 }

PLAIN ENGLISH

Create one named producer inside the Deep Agents framework.

Give it the selected model and exactly one controlled tool: the supported-palette lookup.

Require its answer to match the arrangement-plan schema, then attach saved run state from the checkpointer.

Mount the reusable skill instructions into its private runtime.

Allow reads only in the approved locations; explicitly deny writes and all other reads.

Tell the producer to read its instructions, inspect the supported palette once, and return a compact plan without inventing listening or timeline work.

Build the one user message plus the runtime files that describe this particular job.

Invoke the agent under the job’s thread ID, with a recursion limit of 24.

The proposal has rails

The model can be expressive inside eight named fields, but the domain contract decides what counts as usable. A beautiful answer outside those rails is still invalid.

⏱️

Tempo has a lane

tempoBpm must be a whole number from 78 through 112.

〰️

Contour is enumerable

Melody shape must be falling, rising, or wave—not an invented label.

🎚️

Intensity is bounded

Energy, drum density, and bass motion are numeric controls with explicit minimums and maximums.

🧾

Reasoning stays compact

The rationale must be present and no longer than 400 characters.

💡
Proposal is not authority

Model output becomes useful only after validation; the next module’s compiler—not the model—turns accepted intent into music.
