06 / Interface

The Listening Room is an evidence surface.

The room makes an arrangement legible without pretending to play it. It separates looking from changing, tentative work from saved versions, and comparison from selection.

Selected visual direction

Warm ivory, forest green, burnt orange, editorial typography, and a spacious desktop-and-phone composition—not a stock dashboard.

Start → Producer

Inspect the score

Start offers a direction, a selected producer, optional Sounds and collapsed Creation options. Rewrite/Inspire supplies an editable suggestion, never an automatic submission. Accepted work opens Arrangement and Producer; confirmed activity is public project state, not private reasoning. Lane density is not loudness.

Sounds

Owned sound stays distinct

The browser can record or upload a WAV and audition it through the shared audio controller. Selecting that source for native construction is explicit. The sampled shortlist can receive measured facts and, when authorized, bounded Gemini character opinion. Auditioning the original WAV is not auditioning the native arrangement.

What does each room state mean?

The interface only makes claims supported by the underlying state.

Looking never silently changes scope

Section focus, part inspector, note pitches, clips, routing, and controls are read-only until a Change action is chosen. The direction form then displays its scope and kept parts, and a server preview resolves preservation before submission.

Confirmed steps, unfinished result

A durable plan and confirmed draft can appear during production or safe pause. It remains visibly unselected. A next direction may be drafted while work runs, but is not sent automatically. Motion can show bounded before/after fact changes, not a fabricated note-by-note performance; reduced motion retains the facts.

Before / After / Changes

The paired views share time, pitch scale, and part order. They detect changed note timing/pitch even with equal note counts, plus known clip/control/routing changes. Unsupported alignment or curve cases say “unverified.” Use Before/After is the separate explicit selection action.

Audition your optional recordings

Sounds contains upload, recording, source selection and one HTMLAudioElement with labeled seek/volume controls. Closing the sheet or leaving the room stops playback and releases recording resources. This is source audition, not composition playback. Versions is separate; Usage and Audiotool connection sit under Session options.

Composition scale

Bounded disclosure

Overview lanes cap visible phrase/clip blocks, focused detail pages bars, and part lanes progressively disclose large arrangements.

Interaction primitives

Owned, themed UI

React/Vite, Tailwind, local shadcn-style Base UI components, Lucide, and Motion for React support accessible dialogs, sheets, menus, controls, and responsive layout.

Device evidence

Tested, with limits

Desktop and emulated phone/tablet Chromium journeys cover scope, focus, comparison, reduced motion, and keyboard space. Physical phones and non-Chromium engines remain open.
