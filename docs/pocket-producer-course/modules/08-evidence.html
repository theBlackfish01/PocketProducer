Know what the tests prove—and what they do not.

Pocket Producer protects provider keys, source data, accepted versions, and spend. Its local tests are intentionally provider-free; real-model artistry and current live remote fidelity remain separate questions.

One sentence to remember

Scripted construction proves the workflow can enforce its contract, not that a live model wrote a great song.

These categories should never be silently promoted into one another.

Repeatable and provider-free

Unit and PostgreSQL integration tests cover schema, domain invariants, job/restart/contending-worker behavior, replay, cancellation, protected revisions, source ownership, accounting, and offline Nexus mapping. Chromium journeys exercise create/revise/compare/restore, focus, reduced motion, mobile viewport, and larger scores. Scripted model turns traverse the production tool wiring.

Narrow live facts from earlier work

OAuth consent and encrypted session persistence worked. A completed Sol run produced Midnight Escalator; its mapped project matched live v7 structural readback after reconciliation. Neither that run nor the copy proves heard quality or every supported mapping.

Do not turn unknowns into badges

Full mapping-range live fidelity, source-bearing remote sync, successful live Gemini critique, native heard output, broader real-model creative benchmarks, physical-phone keyboard/safe areas, and Firefox/WebKit remain unverified or deliberately deferred. Public deployment is not part of this milestone.

The operating guardrails

Keys stay on the serverThe ignored root environment file is loaded and validated by server config. Browser bundles receive status, never OpenAI/Gemini credentials. Temporary development identity is loopback-only and refused in production.
External effects are ledgeredA stable effect identity is reserved before dispatch. Known usage is charged once; an ambiguous post-dispatch result retains a reservation rather than becoming a free retry.
Technical ceilings are not permissionStandard and Extended job profiles bound calls, output, time, and per-job cost. They do not authorize spending that amount. The separate installation cap defaults to US$5 and does not reset per job.
Remaining allowance is an upper boundThe 26 September read-only ledger showed US$0.618486 known spent/reserved of US$5. Four Gemini effects have unknown liability; US$4.381514 is not an exact spendable balance. This course made no provider request.
