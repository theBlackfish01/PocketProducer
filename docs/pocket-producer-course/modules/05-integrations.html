Reserve the toll—and count thinking too

A Gemini attempt first reserves an idempotency key under the shared budget lock. The response path accounts for prompt, answer, and hidden thinking tokens even when the JSON is invalid.

CODE · packages/core/src/providers/gemini.ts 
    const response = await client.generateContent({
      model: config.GEMINI_MODEL,
      contents: [{ role: "user", parts: [{ inlineData: { mimeType: "audio/wav", data: bytes.toString("base64") } }, { text: prompt }] }],
      config: {
        maxOutputTokens: 2_048,
        thinkingConfig: { thinkingLevel: ThinkingLevel.MINIMAL },
        responseMimeType: "application/json",
        responseJsonSchema: schema,
        ...(input.signal ? { abortSignal: input.signal } : {}),
        httpOptions: { timeout: Math.min(60_000, Math.max(1_000, new Date(input.job.deadlineAt).getTime() - Date.now())) }
      }
    });
    const text = response.text ?? "";
    responseTextLength = text.length;
    finishReason = response.candidates?.[0]?.finishReason;
    if (text.length > 16_384) throw new Error("Gemini response exceeded the bounded JSON size");
    usage = {
      promptTokens: response.usageMetadata?.promptTokenCount ?? 0,
      candidateTokens: response.usageMetadata?.candidatesTokenCount ?? 0,
      thoughtsTokens: response.usageMetadata?.thoughtsTokenCount ?? 0,
      totalTokens: response.usageMetadata?.totalTokenCount ?? 0
    };
    const outputTokens = Math.max(usage.candidateTokens + usage.thoughtsTokens, usage.totalTokens - usage.promptTokens);
    costMicrousd = tokenCostMicrousd("gemini", config.GEMINI_MODEL, { inputTokens: usage.promptTokens, outputTokens });
PLAIN ENGLISH

Send the real WAV bytes and the purpose-specific prompt to the configured Gemini model.

Bound output at 2,048 tokens and request minimal thinking so reasoning leaves room for the answer.

Require purpose-specific JSON, propagate cancellation, and stop at the job’s deadline.

Capture the returned text length and finish reason without logging the content.

Reject an unexpectedly large response before parsing it.

Record prompt, candidate, thought, and total token counts separately.

Bill the larger trustworthy output count, so hidden thinking is not lost when JSON validation fails.

✦

Aha: a provider response can fail product validation and still consume tokens. Failure handling must preserve both truths: “no usable analysis” and “usage may still be billable.”

Convert the clock once, then read it back

The canonical song uses 960 pulses per quarter note; Nexus uses 3840. The adapter owns that four-to-one conversion, derives region length from decoded WAV duration, and keeps the musical body distinct from the explicit render tail.

CODE · packages/core/src/nexus/adapter.ts 
const musicalBodyNexusTicks =
  canonicalTicksToNexus(composition.durationTicks)
const audioDurationNexusTicks = Math.round(
  secondsToTicks(decoded.durationSeconds, composition.tempoBpm)
)
transaction.update(config.fields.tempoBpm, manifest.tempoBpm)
transaction.update(config.fields.signatureNumerator, 4)
transaction.update(config.fields.signatureDenominator, 4)
transaction.update(config.fields.durationTicks, manifest.projectDurationNexusTicks)
PLAIN ENGLISH

Translate composition positions from 960 PPQ to Nexus’s 3840 PPQ exactly once.

Measure the actual decoded stem, so its one-second tail is not silently discarded.

Write tempo, 4/4 signature, and the longest complete stem into the Nexus Config.

Read the validated document back and require four enabled tracks, four routed regions, and exact timing.

What remains outside

Live proof requires an issued client ID and browser consent. Tokens are encrypted and owner-bound locally; they are never pasted into chat or the browser bundle.

Use the evidence label that fits

A status sentence should say what artifact exists, where it exists, and which boundary has not been crossed. These notebook labels are safe language for reviews and handoffs.

MEASURED “The waveform measurement reports this value.” A measured fact comes from the audio bytes, not the model’s taste.
MODEL OPINION “Gemini observed this, with stated uncertainty.” Advice may guide a revision but does not silently become fact.
LOCAL VERIFIED “Nexus 0.0.17 v3 timing, routing, and per-step recovery verified offline.” This still says nothing about a real remote Audiotool project.
LIVE FAILURE “Gemini produced no successful analysis; the latest two calls ended after dispatch without provider telemetry and remain uncertain/unknown-cost.” Failed or uncertain evidence is not success and must not be silently replayed.

Checkpoint drill

Choose the response that protects truth, cost, and editability. Each scenario asks what you would actually say or do.
