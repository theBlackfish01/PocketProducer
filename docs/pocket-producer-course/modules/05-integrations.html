Reserve the toll before paying it

A Gemini attempt first reserves an idempotency key. If the same attempt already exists, the code reuses a completed answer or returns an honest unavailable result rather than risking duplicate billing.

CODE · packages/core/src/providers/gemini.ts 
    const idempotencyKey = `gemini:${purpose}:${input.hash}:audio-critique-v1`;
    const reserved = await getPool().query<{ id: string }>(
      "INSERT INTO effect(job_id,step,idempotency_key,input_hash,state,provider) VALUES($1,$2,$3,$4,'pending','gemini') ON CONFLICT(job_id,idempotency_key) DO NOTHING RETURNING id",
      [input.jobId, purpose, idempotencyKey, canonicalHash({ hash: input.hash, purpose, measured })]
    );
    effectId = reserved.rows[0]?.id;
    if (!effectId) {
      const prior = await getPool().query<{ state: string; output: { analysis?: AudioAnalysis } | null }>("SELECT state,output FROM effect WHERE job_id=$1 AND idempotency_key=$2", [input.jobId, idempotencyKey]);
      if (prior.rows[0]?.state === "succeeded" && prior.rows[0].output?.analysis) return prior.rows[0].output.analysis;
      return { status: "unavailable", assetHash: input.hash, model: config.GEMINI_MODEL, promptVersion: "audio-critique-v1", purpose, inspectedInterval: { start: 0, end: input.durationSeconds }, measured, observations: [], uncertainty: "A previous Gemini attempt did not complete; it was not repeated to avoid duplicate billing.", suggestedActions: [], repairAction: "none", usage: { promptTokens: 0, candidateTokens: 0, totalTokens: 0 } };
    }
    await getPool().query("UPDATE job SET estimated_cost_usd=estimated_cost_usd+$2 WHERE id=$1", [input.jobId, estimatedCallCost]);
PLAIN ENGLISH

Name this one critique from its purpose, audio fingerprint, and prompt version.

Try to reserve one pending provider effect. A duplicate reservation is deliberately ignored.

Fingerprint the measured input too, so the record says exactly what was submitted.

Keep the new reservation’s ID—if there is one.

No new ID means this exact attempt was seen before, so look up its recorded outcome.

If that earlier attempt succeeded, return its saved analysis instead of calling Gemini again.

If it did not finish, say “unavailable” and explain why it was not repeated.

Only the newly reserved call adds its estimated cost to the job.

✦

Aha: uncertainty is data, not permission to spend again. The safe result can be “we do not know, and we did not double-charge.”

Use the evidence label that fits

A status sentence should say what artifact exists, where it exists, and which boundary has not been crossed. These notebook labels are safe language for reviews and handoffs.

MEASURED “The waveform measurement reports this value.” A measured fact comes from the audio bytes, not the model’s taste.
MODEL OPINION “Gemini observed this, with stated uncertainty.” Advice may guide a revision but does not silently become fact.
LOCAL VERIFIED “Nexus 0.0.17 offline document and local editable-stem manifest verified.” This says nothing about a remote Audiotool project.
NOT LIVE “Gemini has no configured key or live call; Audiotool has no verified OAuth or remote mutation.” Missing proof stays visible.

Checkpoint drill

Choose the response that protects truth, cost, and editability. Each scenario asks what you would actually say or do.

1. The network drops after a Gemini request may have left the server. What should the worker do next?

2. A meter reports a loudness value, while Gemini calls the chorus “crowded.” How should a revision note describe them?

3. A teammate asks whether the export now creates a fully editable Audiotool project. Which answer is accurate?
