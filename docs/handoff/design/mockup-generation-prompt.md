## 1. Option 1 — Listening Room

Use case: ui-mockup. Create one exceptionally polished high-fidelity product UI concept board for "Pocket Producer", a responsive WEB APPLICATION for AI-assisted music creation from user recordings and samples. The image must depict a real in-product working session, never a marketing landing page. Show a large DESKTOP WEB APP viewport on the left occupying about 75% of the board width and a matching narrow MOBILE WEB viewport on the right occupying 22%, with a clear gutter. Both completely visible, flat straight-on with NO perspective distortion and NO laptop hardware or physical phone chassis. Slim browser chrome on desktop and mobile may be used to establish web context. Desktop viewport roughly 1440x940 and mobile viewport roughly 390x844, thoughtfully recomposed responsive layout rather than a shrunken desktop. Crisp readable UI text and generous spacing at high resolution, ideally landscape 2560x1600. Device screen content dominates the image, very little outer presentation padding. Small outside labels "DESKTOP" and "MOBILE" only. Treat this as the work of a top-tier product designer: decisive hierarchy, exquisite typography, mature interaction design, beautiful nuanced materials, consistent iconography and alignment. No watermarks, no explanatory arrows, no lorem ipsum, no technology framework names, no random charts or analytics, no excessive AI sparkle icons. Show the SAME project in both views: "Night Drive", "92 BPM", "01:04", version "Draft 03". Example supplied audio labels "Glass tap", "Bass loop", "Voice memo". Clear player and play button, a way to add sounds, a voice/text direction input, access to versions, and an optional "Open in Audiotool" desktop action. Example revision text exactly "Keep the melody. Make the drums simpler." Keep text brief and legible. The AI handles production; the interface helps a user listen and direct without needing to operate a complex DAW. These are fictional design explorations, so create a visually complete plausible session state.
DESIGN PHILOSOPHY: Outcome-first. An intimate modern listening room, elegant editorial music culture, warm and optimistic. Light interface with warm ivory background #F3F0E8, inky black text #232422, vivid burnt-orange #E75C36 accents, deep forest details. Typography uses a beautiful large editorial serif only for the track title and clean, carefully sized humanist sans for everything else. Create a bespoke abstract album artwork: a hazy burnt-orange circle crossing a midnight-green horizon with subtle film grain; prominent but serves the music. This artwork is the only imagery.
DESKTOP LAYOUT: Narrow 160px left navigation with understated wordmark Pocket Producer, "Create", "Sessions", and three quietly listed recent session names; bottom profile dot. The main listening area is spacious with breadcrumb "Sessions / Night Drive", top-right Audiotool/export actions. Prominent editorial Night Drive title, subtitle "A little warmer. A little less hurried.", then an elegant broad listening composition: medium-large square cover artwork on left, a restrained waveform and clear transport on right with time 00:24 / 01:04. Below, a fine segmented line "Intro / Groove / Lift / Outro" rather than a complex timeline. A row of three tiny waveform source tiles labeled Glass tap, Bass loop, Voice memo, each with a small audition button. At lower center, a wide refined ivory input with orange circular microphone and "What would you change?" plus a short current instruction shown above it; one single compact assistant note "Drums simplified. Melody preserved." Older versions are tucked into a small Draft 03 dropdown next to "Compare", not a giant chat feed. Use open space and rules rather than a grid of rounded cards. MOBILE: project title, larger cover art, clear player, compact source chips, "Draft 03 / Compare", instruction, and a thumb-friendly sticky voice/text bar. The player is the main subject. This should feel like a premium music product, tactile through typography and restraint, never a generic productivity dashboard.
